# Steel Plate Fault Classification

Classify types of surface fault on steel plates from measured plate properties.

## Approach

- Outlier analysis, keeping outliers that carry class information
- Log transforms for skewed columns
- Comparison of Logistic Regression, Decision Tree, KNN, Naive Bayes, SVM and Random Forest
